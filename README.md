# PS2 Webcore Launcher (PS2WCL)
Windows x64 ONLY

A launcher with a PS2-style interface.

Controls:
+ Cross = Enter
+ Circle = Esc
+ Triangle = Tab
+ Square = Shift
+ R1 = F5
+ Start = Space
+ L1 = Del
